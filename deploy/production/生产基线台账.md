## 部署和外部能力

- AI 平台使用独立 Compose 项目、容器网络、数据卷、PostgreSQL、Redis 和日志目录。
- Bridge 未发布宿主机端口，仅连接内部 Docker 网络；计划由防火墙单元限制到 HZC 网段，但该单元尚未在生产安装，访问限制仍待 P08 验收。
- Bridge 到 New API 的上游已使用独立 Docker 网络内的 HTTPS，并通过内网 readiness 与只读 `GET /v1/models` 验证；商户 Key 已保存在服务器受控配置中。上述检查不代表真实模型推理、共享余额或扣费验收通过。
- 预上线阶段关闭真实支付、真实充值和真实模型调用。后续开放前须完成凭据、恢复、回滚及真实业务验收。
- 回滚范围仅包括 AI 平台自己的发布、Compose 配置和独立 Nginx 配置；不得停止、覆盖或清理 HZC 服务和数据。

## 凭据来源

- 服务器只读核验使用运维者本机受控 SSH 配置；文件权限须为 `600`，不得回显内容。
- AI 平台运行秘密由服务器 `<AI平台数据目录>/production.env` 提供；只核对设置状态，不复用 HZC 运行配置，也不读取或记录实际值。
