| 阶段 | 内容 | 状态 | 通过条件 |
| --- | --- | --- | --- |
| P00 | 确认平台网址、Bridge 边界、部署范围和预上线备份基线 | ✅ 已完成 | 管理方与商家共用 `https://ai.al-bei.cn`；Bridge 仅内部调用；真实支付与模型关闭 |
| P01 | 只读盘点服务器 | ✅ 已完成 | 系统资源、`/data`、Docker、Nginx、时间和防火墙有脱敏证据；见 `生产对照核验.md` |
| P02 | 核验 DNS、HTTPS 和证书 | ✅ 已完成 | DNS、证书、HTTP 跳转、证书续期模拟均通过；AI 域名已隔离到独立站点，应用尚未发布时明确返回 503。应用健康检查在 P07 验收 |
| P03 | 代码、镜像和发布包门禁 | ✅ 已完成 | 生产配置无默认密码；镜像固定版本、发布包无秘密。根 Dockerfile 的依赖下载阶段无输出后，改用同版本固定工具链离线编译并手动组装镜像；详细证据见 `生产对照核验.md` |

| P06 | 支付、模型和文件等外部能力 | ⏸️ 预上线后置 | 真实支付和真实模型保持关闭；未来开放前须单独验收 |
| P07 | 平台首次初始化与发布 | ✅ 已完成 | 首个管理员已创建；`/` 直接跳转 `/sign-in`；登录页与 API 健康检查通过；HZC 入口未受影响 |
| P08 | HZC 商家与 Bridge 接入验证 | ⏳ 进行中 | Bridge 仅监听 HZC Docker 网络的固定地址；防火墙脚本先核对 Compose 固定地址与监听地址，失配时拒绝应用规则；发布 New API Compose 前先迁移 TLS 证书到独立目录并确认只读挂载与 Certbot 钩子一致；先安装并启用 Bridge 防火墙 systemd 单元，验证访问规则和 Docker 重启恢复，再安装或启用硬依赖该单元的 Bridge systemd 服务；配置正式凭证并更新 HZC 入口时保持 HZC AI 开关关闭，仅做健康、凭证和只读模型目录等无推理、无扣费校验。真实推理、充值、共享余额和扣费验收须先通过 P06 并另行授权 |
| P09 | 回滚与收口 | ⏳ 待处理 | 恢复、回滚、剩余风险和后续事项均有证据 |

P05 后续加固（未部署）：本地候选将备份文件名加入进程号，并将 systemd 单次运行上限设为 1 小时。该候选尚未部署，不属于上表 P05 已完成的验收证据。

## 禁止操作

- 不连接或修改 HZC 生产数据库，不访问本机 `127.0.0.1:13306`。
- 不停止、覆盖或清理 HZC 服务、数据卷、Nginx 配置或备份。
- 不开放真实充值或调用真实模型，直到对应门禁单独通过。
- 不执行 `docker compose down -v`，不删除 AI 平台数据库卷。
